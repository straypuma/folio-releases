# Folio

A tiny native macOS portfolio tracker for crypto, cash and Milady / Remilio NFTs: live prices, 7-day charts and
NFT floors, transactions per holding, iCloud sync, a Net Worth widget and a menu bar item.

## Download

Get **Folio-x.y.dmg** from the [latest release](https://github.com/straypuma/folio-releases/releases/latest).

1. Open the DMG and drag **Folio** into **Applications**.
2. Open it. The first time, macOS blocks it because it isn't notarized by Apple: go to
   **System Settings ▸ Privacy & Security**, scroll down and click **Open Anyway**. After that it opens normally.

**Requires** an Apple silicon Mac on macOS 15 or later.

## Updates

Folio checks for updates once a day and offers to install them (or **Folio ▸ Check for Updates…**).
Updates are signed, so only builds from this page are accepted.

This repository only hosts releases; the source is private.
